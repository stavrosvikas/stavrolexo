# ΣΤΑΥΡΟΛΕΞΟ LUBEN — Summer 26

Σταυρόλεξο 60 ερωτήσεων για το luben.tv, σε μορφή φυλλαδίου 4 σελίδων.
Static site — καθόλου build step, καθόλου dependencies. Ανοίγει και με διπλό
κλικ στο `index.html`.

## Δομή

```
index.html          το τεύχος (header από luben-web-header-template.md)
css/style.css       χαρτί, μελάνι, γύρισμα σελίδας, πληκτρολόγιο
js/sfx.js           ήχοι με WebAudio — κανένα αρχείο ήχου
js/storage.js       localStorage — ό,τι γράφεις μένει γραμμένο
js/book.js          τα 4 φύλλα σε 3D, σύρσιμο και γύρισμα από τη γωνία
js/grid.js          πλέγμα, επιλογή λέξης, ζουμ, έλεγχος
js/dots.js          ένωσε τις τελείες
js/keyboard.js      ελληνικό πληκτρολόγιο (+ λατινικό mapping σε desktop)
js/app.js           δέσιμο όλων
data/questions.json οι 60 ερωτήσεις — πηγή αλήθειας, γράφεται στο χέρι
data/grids.json     τα 2 πλέγματα (παράγεται)
data/puzzle.js      questions + grids μαζί, για να δουλεύει με file:// (παράγεται)
data/dots.js        οι τελείες του προσώπου (παράγεται)
tools/              οι γεννήτριες — τρέχουν offline, ποτέ στον browser
assets/             γραφιστικά: masters + web εκδοχές
```

## Δομή του τεύχους

Κάθε φύλλο έχει **δύο πραγματικές πλευρές**, όπως στο χαρτί: μπροστά η σελίδα
του, πίσω η αριστερή σελίδα του επόμενου ανοίγματος. Οι ορισμοί κάθε
σταυρόλεξου είναι τυπωμένοι στην **πίσω όψη του προηγούμενου φύλλου** — γυρνάς
τη σελίδα και έρχονται μαζί της. Τα φύλλα τσακίζουν μόνο στην ελεύθερη ακμή
τους, ποτέ από τη ράχη.

## Εργαλεία

Όλα τρέχουν offline. Το site δεν εκτελεί τίποτα από αυτά.

```bash
python tools/optimize_grid.py     # data/grids.json  (~8 λεπτά)
python tools/export_js.py         # data/puzzle.js  = questions + grids
python tools/svg_to_dots.py       # data/dots.js    από το assets/dots-face.svg
python tools/make_web_assets.py   # cover-web.jpg, og.jpg, q58-web.png
```

Όταν αλλάξει το εξώφυλλο: αντικατέστησε το `assets/cover.png` (1200×1600) και
τρέξε `make_web_assets.py`.

Το `make_web_assets.py` **δεν πατάει ποτέ αρχείο φτιαγμένο στο χέρι**: αν το
παράγωγο (`cover-web.jpg`, `og.jpg`, `q58-web.png`) είναι πιο πρόσφατο από την
πηγή του, το παραλείπει. Με `--force` ξαναφτιάχνονται όλα.

Τα πρωτότυπα (`cover.png`, `q58.png`) μένουν στο repo ως masters αλλά **δεν
κατεβαίνουν** ποτέ στον χρήστη· το site σερβίρει τις web εκδοχές.

## Αποφάσεις — και το γιατί

**Ένα responsive app, όχι ξεχωριστό mobile/desktop.** Αυτό που αλλάζει δεν
είναι το περιεχόμενο αλλά το επίπεδο εισόδου: σε κινητό δικό μας πληκτρολόγιο
+ auto-zoom, σε desktop φυσικό πληκτρολόγιο και ολόκληρο το πλέγμα.

**Δικό μας πληκτρολόγιο, όχι το native.** Το native σε κινητό ανοίγει με
αγγλικό layout, βάζει autocorrect και πετάει το viewport.

**Criss-cross πλέγμα, όχι πραγματικό σκανδιναβικό.** Μετρήθηκε: με αυτές τις
60 λέξεις η πυκνότητα κολλάει στο 47% ό,τι κι αν κάνεις — δεν φταίει ο
αλγόριθμος, φταίει ο κανόνας ότι κάθε γράμμα εκτός διασταύρωσης πρέπει να έχει
κενά πλάγια. Δοκιμάστηκαν και απορρίφθηκαν:

| Δοκιμή | Αποτέλεσμα |
|---|---|
| Μονοσέλιδο με 60 λέξεις | 32×32, πυκνότητα 37% — χειρότερο σε κινητό |
| 40/20 αντί για 30/30 | 27×27, χειρότερο από το 30/30 |
| +20 λέξεις γεμίσματος | πυκνότητα 35→37%, απλώς μεγάλωσε το πλέγμα |
| Χωρίς τη ΜΠΑΧΑΛΟΣΑΤΑΝΙΣΤΡΙΕΣ | ίδια πυκνότητα, μόνο 2 κελιά στενότερο |

Για πραγματικό σκανδιναβικό (~70%) χρειάζονται παράλληλες γειτονικές λέξεις,
άρα ελληνικό λεξικό και backtracking solver. Ξεχωριστό project — το
`grids.json` έχει ίδια δομή, οπότε αν γίνει, αλλάζει μόνο το αρχείο δεδομένων.

**Τα κενά κελιά μένουν χαρτί, δεν βάφονται μαύρα.** Στο 47% πυκνότητα ένα
μαύρο πλέγμα θα φαινόταν τρύπιο. Έτσι οι λέξεις «επιπλέουν» καθαρές.

**Έλεγχος μόνο σε γεμάτη λέξη.** Μπλε = σωστή, κόκκινη = λάθος. Ανά γράμμα θα
επέτρεπε brute force.

## Παλέτα & τυπογραφία

**Λευκές σελίδες.** Το magenta μπαίνει σε κλίμακα (`--m-05` … `--m-100`) με
κανόνα: όσο μεγαλύτερη η επιφάνεια, τόσο πιο ξεπλυμένος ο τόνος. Πλήρης
κορεσμός μόνο σε μικρές λεπτομέρειες — ενεργό κελί, βελάκια, αριθμοί.
Η επιλεγμένη λέξη παίρνει `--m-10`, το κελί που γράφεις `--m-40`.

Γράμματα στα κελιά: **Mynerve** (handwriting, με ελληνικά). Πληκτρολόγιο και
UI: Roboto — τα πλήκτρα θέλουν καθαρά γράμματα, όχι χειρόγραφα.

Μελάνι: μαύρο όσο γράφεις, **magenta** όταν η λέξη είναι σωστή, **κόκκινο με
κυματιστή υπογράμμιση** όταν είναι λάθος. Η υπογράμμιση υπάρχει ώστε το λάθος
να μη διακρίνεται μόνο από το χρώμα.

## Διαστάσεις εξωφύλλου

Το τεύχος κλειδώνει σε **3:4** σε οθόνες ≥760px. Σε κινητό γεμίζει την οθόνη.

Το εξώφυλλο έχει **artboard 3:4** (`.cover-art`) που χωράει πάντα ολόκληρο μέσα
στη σελίδα, όποιο κι αν είναι το σχήμα της συσκευής:

| | |
|---|---|
| Artboard | **1200 × 1600** (3:4) |
| Safe zone | **1080 × 1440** — το εσωτερικό 90%, κεντραρισμένο |
| Bleed | ό,τι περισσεύει γύρω γεμίζει με `--cover-bleed` |

Δηλαδή: σχεδίασε στα 1200×1600, κράτα λογότυπα και τίτλους μέσα στο 1080×1440,
και βάλε το `--cover-bleed` ίδιο με το χρώμα στην άκρη του γραφιστικού ώστε το
περίσσευμα να δένει.

## Ήχος

Δεν κατεβαίνει κανένα αρχείο ήχου — όλα συντίθενται με WebAudio (`js/sfx.js`):
το γύρισμα σελίδας είναι θόρυβος περασμένος από bandpass που σαρώνει, δηλαδή
χαρτί που τρίβεται.
